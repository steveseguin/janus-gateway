Janus Gateway (Rust) Demos

Interactive demos for the Rust rewrite of Janus WebRTC Server

VideoRoom — Bouncing Ball

Publishes a canvas-captured bouncing ball + sine tone to VideoRoom (room 1234) via the Janus API. Uses janus.js for signaling over WebSocket.

Janus API

Streaming Viewer

Watches a Streaming plugin mountpoint (ID 1) via the Janus API. Uses janus.js for signaling over WebSocket.

Janus API

WHIP/WHEP Demo

Publishes via WHIP (RFC 9725) and subscribes via WHEP using plain HTTP + RTCPeerConnection. No janus.js needed — pure standard WebRTC signaling.

WHIP/WHEP

WHEP Player

Standalone WHEP viewer — paste a Publisher ID to subscribe to any active WHIP stream. Open in multiple tabs to test fan-out.

WHEP

Janus API demos use janus.js and require a WebSocket connection to the Janus server (port 8188 by default).
WHIP/WHEP demos use standard HTTP signaling and only need the HTTP transport (port 8088 by default).
