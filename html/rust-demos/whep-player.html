WHEP Player

Rust Janus Server • Subscribe to any WHIP publisher via WHEP • All demos

Paste a Publisher ID from the WHIP/WHEP demo to subscribe to that stream from this separate page. This demonstrates that WHEP subscribers are independent clients — you can open multiple tabs to watch the same publisher simultaneously.
Protocol: HTTP POST of SDP offer to /whep/{publisher_id} → 201 + SDP answer. No janus.js required.
